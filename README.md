# PiggieTrigger
PiggieTrigger 是一款基于 Android 无障碍服务（AccessibilityService）开发的高效按键重映射工具。通过拦截硬件音量键，为设备提供无感的自动手势与快捷操作支持。

---

## 核心功能

* **音量上键 (`Volume Up`)**：触发屏幕指定坐标的模拟点击手势。
* **音量下键 (`Volume Down`)**：触发系统全局返回（Back）操作。
* **极简悬浮窗**：轻量级控制台，支持快速开启/关闭按键拦截与手势服务。
* **纯净无打扰**：未开启悬浮窗或禁用服务时，自动放行音量键，恢复系统原生音量调节功能。

## 包名与构建配置

| 配置项 | 值 |
| :--- | :--- |
| **应用名称** | PiggieTrigger |
| **Package Name** | `com.piggie.iemtrigger` |
| **最低支持系统** | Android 8.0 (API Level 26) 及以上 |
| **核心权限** | `BIND_ACCESSIBILITY_SERVICE`, `SYSTEM_ALERT_WINDOW` |

## 快速使用指南

### 1. 软件界面操作
1. 打开应用，点击 **`开启无障碍服务`**，在系统设置中找到 **PiggieTrigger** 并开启。
2. 点击 **`开启悬浮窗权限并显示`**，授予“显示在其他应用上层”权限。
3. 悬浮窗显示后，切换至目标应用页面，按 **音量上键** 执行模拟点击，按 **音量下键** 返回。
4. 如需停止服务，点击应用内的 **`关闭悬浮窗`**；若需退出，点击 **`退出应用`**。
